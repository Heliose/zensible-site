The runtime

Inside the runtime, request to outcome

Compiled per tenant. Cached by configuration hash.

Entry

Teams · Slack · WhatsApp · web widget · public portal. The chat layer normalises every channel to one conversation model. The AI service API verifies JWTs against your IdP and resolves tenant, user and thread.

Agent runtime

Root router. Tier 1 supervisors. Tier 2 workers. A swarm node for parallel fan-out across workers, returning one synthesis to the supervisor.

Model plane

Per-tenant gateway routing across Anthropic, OpenAI, Google and self-hosted SLMs. Retries, tokens and cost captured per call.

Memory and state

PostgreSQL checkpoints per thread. Redis configuration and broker. Per-knowledge-base vector store isolation.

Observability and hands

Versioned prompts, trace and cost capture. Uniform API wrapper, HR systems, workflow manager, RPA service and notification channels.
